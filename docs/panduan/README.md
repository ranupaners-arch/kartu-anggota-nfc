# Panduan Pengguna: Kartu Anggota NFC

Panduan singkat untuk dipakai saat uji lapangan (M4) dan sesudahnya. Pilih sesuai peran Anda:

| Peran | Memakai | Panduan |
|---|---|---|
| **Petugas Scan** | App Android | [Petugas Scan](petugas-scan.md) |
| **Super Admin** / **Admin Divisi** (pengurus) | Dashboard web (+ app untuk scan & terbitkan kartu) | [Pengurus](pengurus.md) |
| **Anggota** | App Android (opsional) | [Anggota](anggota.md) |
| Penanggung jawab acara | - | [Checklist Hari-H](checklist-hari-h.md) |

Perbedaan pengurus:

- **Super Admin**: semua fitur: anggota, kartu, pengguna, perangkat, log, pengaturan.
- **Admin Divisi**: kegiatan divisinya + kegiatan umum, pengajuan izin, tinjauan, rekap divisinya,
  dan **melihat** anggota divisinya. Tidak bisa mengubah anggota, kartu, pengguna, atau pengaturan.

Akun dibuat oleh Super Admin di dashboard → **Pengguna & Peran** → **Tambah Pengguna**. Password
sementara tampil sekali setelah akun dibuat; sampaikan langsung ke pemiliknya.

Untuk pemasangan server, lihat [deploy.md](../deploy.md).
